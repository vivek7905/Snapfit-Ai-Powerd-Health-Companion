# SnapFit – Your AI Health Companion

> **Making Healthy Living as Easy as Social Media**

SnapFit is an AI-powered daily health companion designed to make nutrition tracking and healthy habit-building simpler for busy students and working professionals. Instead of relying only on manual calorie entry, users can log meals through multiple input methods and receive personalized health insights.

---

## ✨ Key Features

- **AI Food Recognition** — Upload a food photo to estimate the meal's nutritional values.
- **AI Chat Logging** — Describe what you ate in natural language.
- **Voice Meal Logging** — Log meals using hands-free voice input.
- **QR / Barcode Scanner** — Identify packaged food products and retrieve nutrition information when available.
- **AI Health Coach** — Get guidance based on logged meals and personal goals.
- **Daily Health Score** — View a simple daily score based on tracked health habits.
- **Smart Dashboard** — Review calories, protein, water intake, activity, and goal progress.
- **Health Timeline** — See meals, hydration, and activities in a clean daily feed.
- **Analytics** — Track nutrition and health trends over time.
- **Meal Suggestions & Reminders** — Support consistent, healthier daily routines.

---

## 🎯 Problem Statement

Busy lifestyles can make it difficult to maintain healthy eating and activity habits. Traditional calorie-tracking apps often require repetitive manual input, which can make users lose motivation.

SnapFit aims to reduce this friction with convenient meal logging, clear progress summaries, and personalized guidance.

---

## 💡 Our Solution

SnapFit brings multiple meal-entry methods and health insights into one easy-to-use experience:

1. Add a meal using a photo, chat, voice, or barcode scan.
2. Review the detected food and estimated nutrition information.
3. Confirm or adjust the entry when needed.
4. View updated dashboard metrics and daily progress.
5. Use personalized suggestions to build healthier habits.

> **Note:** Nutrition values generated from photos or descriptions are estimates. Packaged-food barcode scans depend on the availability and accuracy of product data.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the repository
```bash
git clone [https://github.com/vivek7905/Snapfit-Ai-Powerd-Health-Companion.git](https://github.com/vivek7905/Snapfit-Ai-Powerd-Health-Companion.git)
cd Snapfit-Ai-Powerd-Health-Companion
2. Install dependencies
Bash
npm install
3. Setup environment variables
Create a .env file in the root directory and add your API credentials:

Code snippet
VITE_GEMINI_API_KEY=your_api_key_here
4. Run the development server
Bash
npm run dev
🔐 Privacy & Responsible Use
Do not commit personal health data, passwords, or private API keys.

Store sensitive tokens inside local .env files.

Treat AI-generated nutrition values as estimates, not medical prescriptions.

Consult a qualified healthcare professional for medical or clinical dietary advice.
